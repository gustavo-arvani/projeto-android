📱 Projeto Android

Este projeto consiste em uma página web desenvolvida com HTML5 e CSS3, com o objetivo de apresentar informações sobre o sistema Android de forma organizada, responsiva e visualmente agradável.

🔗 Acesse o projeto online:
👉 https://gustavo-arvani.github.io/projeto-android/

🚀 Sobre o projeto

O projeto foi desenvolvido como parte dos estudos em desenvolvimento web, inspirado no curso de HTML e CSS do Curso em Vídeo.

A proposta foi criar um site completo, aplicando conceitos fundamentais de estruturação, estilização e responsividade.

🧠 O que foi praticado
Estrutura semântica com HTML5
Organização de conteúdo (textos, imagens, vídeos)
Estilização com CSS3
Uso de cores, fontes e layout
Responsividade para diferentes telas
Boas práticas de organização de código
🛠️ Tecnologias utilizadas
HTML5
CSS3
📱 Funcionalidades
📄 Página informativa sobre o Android
🎨 Layout moderno e organizado
📱 Design responsivo (adaptável para celular)
🧭 Navegação simples e intuitiva
